# The Snack Shack

A static student snack-club menu built with HTML, CSS, and JavaScript. No build step, framework, accounts, or backend.

Open `dist/index.html` in a browser, or serve the `dist` directory with any static web server.

Edit the menu prices, descriptions, and pickup details in `dist/index.html`. All menu and pickup information is fictional sample content. Category buttons filter the menu; all items remain visible when JavaScript is disabled. Fonts have system fallbacks.

Styling is in `dist/styles.css`, filtering is in `dist/script.js`, and the food artwork is in `dist/assets/snacks.png`.
